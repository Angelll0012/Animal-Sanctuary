 # Animal Sanctuary
 -A website used to save animals who are in need of rescue.


# Technologies Used
-HTML: Semantic structure and form elements.
-CSS: Styling and layout layout (optional/custom).
-JavaScript DOM manipulation, form handling via `FormData`, and date logic computation.

# How to Run the Project
1. Download this repository to your local machine.
2. Ensure you have three essential files in the same folder:
   -index.html
   -style.css
   -script.js
3. Open `index.html` in any modern web browser (Chrome, Safari, Edge, Firefox).
4. Fill out the form fields and click Submit to see your Akan name.
